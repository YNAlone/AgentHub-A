# AgentHub 毕业论文摘要初稿

建议题目：面向软件开发任务的多智能体协作平台设计与实现

适用阶段：选题与开题，2026-11-09。以下采用拟开展研究的表述；完成正式验收和实验后，再改写为定稿摘要并加入真实结果。当前不作效率提升、成本降低或生产可用性已经得到验证的结论。

## 摘要

面向软件开发任务的大语言模型智能体能够辅助完成需求分析、代码生成与测试等工作，但在多智能体协作过程中，仍需解决异构工具接入、任务依赖管理、上下游产物交接以及执行结果验证等问题。针对个人开发者的本地使用需求，本文拟基于 AgentHub 项目设计并完善一个多智能体协作平台，支持从需求输入、计划审核到任务执行、产物验收的完整流程。

平台采用分层架构，通过统一适配器和流式事件协议接入不同智能体运行环境，结合本地数据库与工作空间管理保存会话、运行状态和交付产物。在协作机制方面，采用有向无环图描述任务依赖，以结构化任务契约明确输入、输出与验收条件，并结合独立工作副本、执行证据和代码版本关联，减少并行修改干扰，支持交付结果核验。在可靠性方面，围绕执行审批、上下文管理、检查点恢复和资源预算完善任务生命周期，使执行过程可观察、可控制，并在异常情况下保留必要现场。

本文拟通过功能测试、故障注入和典型软件开发任务的对照实验，对平台进行评价，比较单智能体、基础多智能体及引入任务契约与验收机制的多智能体方案在任务成功率、错误完成率、执行耗时、资源消耗和人工干预等方面的表现，分析其适用场景与局限，为个人本地多智能体协作工具的设计与实现提供工程参考。

关键词：多智能体协作；软件开发；任务调度；任务契约；异常恢复
