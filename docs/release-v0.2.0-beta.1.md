# AgentHub-A v0.2.0-beta.1 — Windows x64

首个面向个人本地使用的 Windows 桌面测试版。安装后可直接运行 AgentHub，无须为应用自身安装 Node.js、pnpm 或启动开发服务器；模型调用需要在应用内配置服务商凭据及相应网络连接。

## 本版内容

- 本机单聊与多 Agent 协作、项目管理、工作区、附件拖放和产物预览。
- 持久化消息队列、任务中断恢复、上下文压缩及长期记忆。
- 修复桌面认证目录不一致，支持默认数据目录及 `AGENTHUB_DATA_DIR` 覆盖。
- 修复打包遗漏服务端依赖，随包提供 SQLite 原生模块、Claude/Codex 当前平台运行时和 AgentHub MCP 桥接脚本。
- 清理动态文件追踪意外带入的开发文件；安装包不包含本机配置、配对凭据或用户数据库。

## 安装与数据

下载 Release 附件 `AgentHub Setup 0.2.0-beta.1.exe`，运行安装向导，可选择安装目录。`SHA256SUMS.txt` 提供 SHA-256 校验值，许可证为 AGPL-3.0-only；对应源码见本 Release 标签。

默认数据目录为 `%APPDATA%\AgentHub\data`。升级或回退前，请退出应用并备份整个数据目录；不要只复制打开状态的 SQLite 主文件。旧版回退应同时恢复相匹配的数据备份。此版不提供自动更新。

应用启动不依赖全局 Node.js 或 Git；Agent 执行项目构建、Git 操作等任务时，仍需要该任务使用的工具链。联网搜索另需 Tavily 配置。

## 验证范围与限制

已通过 326 项单元/集成测试（5 项跳过）、16 项浏览器测试、TypeScript 检查、ESLint、生产构建和 Electron 编译。新增打包回归测试调用真实 electron-builder 复制逻辑，覆盖服务端依赖漏打问题。

在 Windows 11（10.0.26100）将 NSIS 安装包安装到仓库外临时目录，已验证首次启动、默认数据目录、自动认证、未授权 API 拒绝、创建对话、Custom 适配器流式回复及重启后消息保留。测试隔离了用户配置，并从 PATH 移除 Node/Git；安装后的 Claude/Codex 二进制均通过版本启动检查。静默安装和卸载均成功，测试安装已清理。

这是预发布版本，仅发布 Windows x64 安装包，大小约 356 MiB，体积仍待优化。安装包尚未签名，Windows 可能显示未知发布者或 SmartScreen 提示；尚未进行干净虚拟机和多台设备兼容性验收。

自动化模型请求使用本机模拟服务。Claude/Codex 平台二进制的启动验证不等同于真实模型、账号登录及 SDK 工具链全流程验收；本次没有重新验证付费模型调用。当前运行时仍为 Electron 33，正式稳定版前需推进受支持运行时升级和原生依赖兼容性验证。

服务仅监听本机回环地址，定位为个人本地应用。局域网、手机伴随、团队权限及多租户部署不属于本版发布范围。

维护者可用 `node scripts/verify-desktop.mjs "<安装目录>\AgentHub.exe"` 复验桌面主流程。该脚本使用临时用户目录、本机模型替身和不含 Node/Git 的 PATH，通过后删除测试数据。
