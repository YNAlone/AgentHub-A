# 本机个人版使用说明

本期面向单人本机使用，支持 Electron 和本机浏览器。手机和局域网访问已关闭。

## 启动与配对

更新前关闭旧服务并备份完整数据目录。源码运行默认使用 `.agenthub-data`；指定 `AGENTHUB_DATA_DIR` 时，服务和配对命令必须使用同一目录。启动会自动创建新能力所需的表，保留历史和文件。

```powershell
pnpm install --frozen-lockfile
pnpm dev
```

在另一个 PowerShell 窗口、同一项目目录运行：

```powershell
pnpm local:pair
```

打开终端显示的本机地址，在配对页输入配对码。浏览器会话有效 24 小时，到期后重新配对。生产 Electron 由主进程完成授权，重启时重新授权。

撤销现有浏览器授权：

```powershell
pnpm local:pair -- --rotate
```

轮换不影响服务商 Key。已经泄露的服务商 Key 需要在服务商后台撤销并更换。

## 项目、恢复和记忆

- 点击侧栏“项目与记忆”，创建项目并分配会话；根据已有文件目录生成的建议需手动确认，不移动文件。选择项目后新建对话会自动归属该项目。
- 重启恢复历史、SDK 关联与文件面板；未完成任务显示中断。点击继续后要求 Agent 先核对已执行步骤，旧审批不继续有效。
- 自动压缩默认开启，失败保留原文；超出硬预算会明确报错。配置现有模型和 API 凭证后，摘要与后台提取可以使用该配置，或选择专门的辅助 Agent。
- 个人偏好跨项目，项目记忆仅在该项目使用。推断记忆待确认，来源可查看；不再适用的内容可以停用，错误或敏感内容可以删除。删除记忆不会删除源对话，且阻止从同一来源重新提取。
- “允许后台提取”和“在新请求中使用”是独立开关；设置页同时显示辅助模型用量与提取失败状态。

旧库升级使用应用的启动迁移。此次验证发现 `db:push` 在旧库上会发生重复索引错误，不要把它用于真实旧库升级。详细实现、测试和限制见 [Spec 16](../specs/16-local-personal.md) 与 [开发变更记录](development-change-log.md)。
