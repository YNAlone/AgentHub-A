# 全应用灰阶工作空间界面

状态：用户已授权，已实现。视觉基准为 d77390d 的项目与记忆管理页。

## 范围及工作包

1. UI-01 基础：统一字体、浅深色 tokens、按钮、输入、弹窗、下拉、标签、焦点与减少动画；保留错误/风险/成功的语义色。
2. UI-02 导航与主页面：侧栏作为导航，对话、Agent 管理、产物库、用量分析进入主区域；保持会话状态及文件/产物预览能力。
3. UI-03 对话与工作区：空状态、消息、输入器、工具/调度/审批、引用、文件树、编辑器和产物预览统一密度和边框。
4. UI-04 全部表单与状态：配对、设置、Agent 创建/编辑、会话创建/成员、目录/文件选择、全局搜索与帮助弹窗统一；手机伴随已停用，本期不启用或改造独立遗留移动应用。用户生成的产物内容不重绘，只统一宿主界面。
5. UI-05 验证与交付：浅色/深色、窄窗口、主要页面和弹窗实屏，聊天与管理 E2E，类型/lint/构建；逐文件同步，保留用户改动，记录提交。

## 视觉契约

- 暖中性白色主背景、浅灰侧栏、黑白主操作；细分隔线与克制圆角，无品牌蓝色大面积背景。
- 采用现有 Geist 与中文无衬线回退；正文 13–14px，辅助文字 11–12px，主页面标题 26–28px。
- 主页面共享标题/说明、内容宽度与留白；数据列表用统一行或卡片，空状态提供清晰下一步。
- 现有 API、数据结构、SSE、沙箱和审批语义不变。可见导航变化不得阻断原有操作。
- 主要内容可滚动，弹窗有最大高度，键盘焦点清晰；窄屏保留导航入口。

## 验收清单

- 对话创建、发送、结束、切换与归档；工具/审批及文件预览入口仍可用。
- Agent 库能创建/编辑；产物库能检索/预览；分析能显示及跳转会话。
- 配对、设置、搜索和辅助弹窗均使用统一基础控件。
- 项目与记忆沿用已认可布局，接入一致全局主题。
- 变更及实际检查结果写入 docs/development-change-log.md。
